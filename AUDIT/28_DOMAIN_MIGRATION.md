# Domain-migration readiness

The migration is executed. Source fallbacks, `FRONTEND_URL`, canonical metadata, sitemap/robots, CORS origin, Pages custom domain, Worker deployment, GitHub deployment secrets, and Resend sender configuration now use `swiftjob.online`. The new zone has an active DNS-only CNAME to `swiftjob-systems.pages.dev`; Pages reports the custom domain and certificate active. Live checks cover the homepage, careers, job, login, legal, API, admin read-only routes, logo asset, sitemap, robots, and outbound custom-mail delivery on the new hostname.

The remaining production gate is inbound mail. Resend reports sending enabled but receiving disabled. The new zone still uses SpaceMail MX records, and `hr@swiftjob.online` bounced during the controlled contact-form test because no mailbox exists. The Cloudflare token can manage DNS and verified destination addresses but receives 403 for Email Routing Settings/Rules; add those permissions to the same token or create the three addresses in the active mail provider, then rerun the contact, application, status, and reply-to receipt checks.
