# Domain-migration readiness

The migration is executed. Source fallbacks, `FRONTEND_URL`, metadata, sitemap/robots, CORS origin, Pages custom domains, Worker deployment, GitHub deployment secrets, and Resend sender configuration use `swiftjob.online`. The zone has an active DNS-only CNAME to `swiftjob-systems.pages.dev`, and `www.swiftjob.online` is also active with SSL. Live checks cover the homepage, careers, job, login, legal, API, admin read-only routes, logo assets, sitemap, robots, and outbound custom-mail delivery on the new hostname.

Cloudflare Email Routing is enabled for both `swiftjob.online` and the legacy `payservice.top` zone. The Cloudflare MX, DKIM, and SPF records are present for the new zone, and all legacy SpaceMail MX, SPF, and autodiscover records have been removed. The requested Gmail destination is verified. The four named aliases and catch-all on `swiftjob.online` are active and point to that destination. Every existing active rule on `payservice.top` (including its catch-all) was also updated to the same Gmail destination. A controlled inbound message sent to `hr@swiftjob.online` appears in Cloudflare Activity Log with result `Forwarded`. Visual inbox placement cannot be checked here without the destination Gmail session.
