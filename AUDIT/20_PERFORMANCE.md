# Performance review

The production Vite build succeeds. Route-level lazy loading was added after the baseline showed a single approximately 1.16 MB JavaScript chunk. The current initial `index` chunk is approximately 324.71 kB (105.14 kB gzip), CSS is 235.20 kB (41.61 kB gzip), and candidate/admin pages load separate route chunks. The largest remaining lazy chunk is ContactsAdmin at approximately 352.20 kB (120.07 kB gzip), so further splitting should follow profiling rather than guesswork.

Live HTTP baseline after the current Worker deployment recorded `/api/healthz` 1,434 ms, `/api/jobs` 996 ms, `/sitemap.xml` 673 ms and protected 401 boundaries between 180–779 ms. A fresh live lab trace measured homepage LCP at 837 ms and CLS at 0.00, with TTFB 159 ms; field CrUX data and INP remain unavailable. Lighthouse desktop and mobile both scored 100 for Accessibility, Best Practices, SEO, and Agentic Browsing. The remaining performance opportunity is the bundled application CSS render-blocking request; no measured Web Vital is failing. Full evidence is in `evidence/performance-closure.json` and `evidence/current-live-verification-2026-09-13.json`.
